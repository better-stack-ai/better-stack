# Newsletter PR evidence

Captured from the generated Next.js application at source commit `0507130a`.
The demo uses a simulated email adapter; no external email is sent.

list, campaign editor, test send, send confirmation, and campaign results.
The WebP files include those steps and editor/subscriber views at 390 px.

`campaign-preview.webp` shows the subsequent secure Markdown preview typography
correction, with headings and list styles retained and raw HTML disabled.
